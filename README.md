# 📱 Excel LearnHub

A modern **Flutter mobile learning application** designed to help users explore, learn, and track their progress across various programming courses. The app provides an interactive and user-friendly experience with real-time data integration and secure authentication.

---

## 🚀 Features

✅ **User Authentication (Firebase)** – Secure login and signup using email and password
🏠 **Home Screen** – Browse featured and popular programming courses
📚 **Course Details** – View full course information, lessons, and progress
👤 **Profile Management** – Display user info, enrolled courses, and learning progress
🔍 **Search & Filter** – Quickly find courses by name or category
⭐ **Bookmark Courses** – Save favorite courses for easy access
⚙️ **Dynamic Data Integration** – Fetch real-time content via API
💡 **Error Handling & Loaders** – User-friendly loading indicators and retry options

---

## 🧭 App Navigation Flow

```
Splash Screen → Login / Signup → Home (Explore Courses) → Course Details → Profile
```

The vision of **Excel LearnHub** is to make coding education more accessible and engaging for beginners.

## 🧰 Installation & Setup

### 1️⃣ Prerequisites

Before starting, make sure you have:

* **Flutter SDK** (latest stable version)
* **Dart**
* **Android Studio** or **VS Code**
* **Firebase project setup** for authentication
* A working **internet connection**

Check Flutter installation:

```bash
flutter doctor
```

---

### 2️⃣ Clone the Repository

```bash
git clone https://github.com/afaqofficial44-eng/Excel-LearnHub.git
cd Excel-LearnHub
```

---

### 3️⃣ Install Dependencies

```bash
flutter pub get
```

---

### 4️⃣ Run the App

Connect your emulator or mobile device, then run:

```bash
flutter run
```

---

### 5️⃣ Build for Production

To generate a release build (APK):

```bash
flutter build apk --release
```

To generate an iOS build:

```bash
flutter build ios --release
```
